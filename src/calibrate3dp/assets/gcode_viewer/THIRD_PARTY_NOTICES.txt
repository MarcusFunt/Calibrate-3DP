Calibrate-3DP G-code preview — bundled software notices
========================================================

The G-code preview bundle is shipped as local static assets with Calibrate-3DP. These notices accompany the bundle at runtime. Chestnut Labs' parser and renderers process the selected artifact on this computer; Calibrate-3DP does not load the hosted demo or send a file to a service.
