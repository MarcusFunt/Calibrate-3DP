# Archived GUI Plan — Superseded

This file records the earlier Dear PyGui implementation plan from 2026-10-08. It is retained as historical context and is no longer an active plan.

The project direction has since changed:
- PySide6/Qt is the target GUI.
- The application is printer-centric and includes saved printers, a calibration history/dependency graph, plate-code lookup, and the complete manual V1 test suite.
- The current UI is a prototype and must not be treated as the V1 product.
- V1 excludes camera workflows and automatic measurements.

Use the current sources of truth:
- docs/V1_GOAL.md
- ../IMPLEMENTATION_PLAN.md
- ../AGENTS.md
- ../docs/IMPLEMENTATION_STATUS.md
- ../docs/PROGRESS_HISTORY.md

Do not execute the old Dear PyGui task plan. Its implementation details, dependencies, and feature coverage were written for the previous direction.
